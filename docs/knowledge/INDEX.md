# База знаний проекта — индекс

Правила ведения:
1. Каждая тема — отдельный файл в этой папке.
2. Новая тема → создать файл + добавить строку в этот индекс.
3. Перед началом работы в сессии — просмотреть индекс; после значимых решений — дополнить файлы.
4. Пишем кратко и по делу, с датами важных решений.

## Индекс тем

| Файл | Тема | Статус |
|------|------|--------|
| `stack.md` | Стек, структура проекта, команды запуска, порт 8100 | Актуально |
| `image-storage.md` | Хранилище по датам, SHA-256, жёсткие ссылки, SQLite | Реализовано |
| `api-chatgpt.md` | ChatGPT API: эндпоинты, формат, ошибки | Реализовано |
| `design.md` | Дизайн-система: направление, палитра, типографика | Частично |
| `docker.md` | Docker: образ, compose, порт 8100, занятые порты машины | Реализовано |
| `decisions.md` | Журнал ключевых решений (ADR-подобный) | Ведётся |
