# Дизайн

## Направление (обновлено после ревью Льва, 2026-09-07)
- **Принцип Apple**: элемент не используется / не несёт реальной информации → удалить. Работает по скиллу distill.
- Что вычищено по итогам ревью: сайдбар с вкладками-заглушками, карточки-панели, капслок-лейблы, подписи на картинках, мета-строки, декоративный футер.
- Палитра: тёмный нейтрал (оклч, лёгкий холодный подтинт) + один акцент (системный синий). Ноль пестроты.
- Типографика: системный стек (-apple-system / Segoe UI), база 16px, минимум 14px. Лев запретил мельчить.
- Композиция: одна колонка max-width 56rem, sticky-хедер с блюром (единственный «декоративный» элемент, он функциональный).
- Пустые секции (история) скрываются полностью.
- Вход в истории — приглушённые превью (opacity 0.55), выход — обычные: разница видна без подписей.
