# Журнал решений

Формат: дата — решение — почему.

## 2026-09-07
- Python 3.12 + FastAPI как основной фреймворк. (выбор Льва)
- Все зависимости в `.venv` проекта, не глобально.
- Хранилище изображений внутри репозитория: по датам + направление (incoming/outgoing).
- Дедупликация: SHA-256 контент-хеш, файлы именуются `<hash>.<ext>`.
- Docker для сборки; порты проверять на занятость перед выбором.
- Ключи API — в `.env`, не коммитить (есть `.env.example`).
- Дизайн: дашборд, тёмные тона, просто/стильно/без вычурности. Первая вкладка — ChatGPT.
- Скиллы дизайна: impeccable (основной) + typeset (типографика).
- Правило общения: всегда начинать сообщение с обращения «Лев».

## 2026-09-07 (сессия 2)
- Порт стенда: **8100** (свободен, не конфликтует с существующими контейнерами).
- Метаданные изображений: SQLite (`storage/metadata.db`) вместо JSON-sidecar — проще группировать историю.
- Дедупликация: жёсткие ссылки (os.link) в папку дня при повторном контенте + fallback на копию.
- Фронтенд без JS-фреймворков: чистый HTML/CSS/JS, шрифт Golos Text (кириллица), тёмная тёплая палитра OKLCH с латунным акцентом.
- Стиль дашборда по скиллу impeccable: без AI-клише (нет циана/градиентов/полос-акцентов).
- Запросы к OpenAI: /v1/images/edits, gpt-image-1, до 16 картинок, таймаут 300 с.
- Правило работы: агент не запускает и не тестирует приложение; только код + самопроверка (py_compile) — тесты делает Лев.

## 2026-09-07 (сессия 3)
- Make-файлы двумя версиями: `Makefile` (Linux/macOS) + `Makefile.win` (Windows) + шина `make.bat`. Причина: разные пути venv и отсутствие make в Windows по умолчанию.
- Docker-файлы оставлены в корне проекта: один сервис — это идиома; папка `docker/` заведём, только если появятся несколько контейнеров/entrypoint-скриптов.

## 2026-09-07 (сессия 4)
- make.bat переписан в самодостаточный диспетчер (без зависимости от make): цели setup/dev/up/down/restart/logs/rebuild/clean/bootstrap/help. Причина: у Льва make из WinGet не виден cmd (`where make` падал), плюс bat с LF-переводами строк ломался в cmd (`'ul' is not recognized`) — сохранять строго в CRLF.
- Makefile.win удалён как избыточный (bat его заменяет).
- Makefile (Linux): добавлен bootstrap — автоустановка docker/python3 через apt/dnf/pacman, chmod +x для *.sh; рабочие цели зависят от bootstrap.
- `make logs` — потоковый (`docker logs -f`), на обеих платформах.

## 2026-09-07 (сессия 5)
- Добавлен health: эндпоинт `GET /api/health` в FastAPI + healthcheck в docker-compose (python-urllib, т.к. в slim-образе нет curl).
- make (обе версии) после up/restart/rebuild показывает отчёт: статус здоровья контейнера, порт и маппинг, URL/доки/хелс; ожидание до 30 с с WARN при неудаче.
