## О проекте
Тестовый стенд для проверки API разных нейросетей (генерация изображений).
- Пользователь отправляет определённое количество картинок через API → получает ответ от нейросети.
- Каждая вкладка интерфейса = отдельный интерфейс для работы с отдельной моделью (вкладки концептуально связаны с API-ключами в `.env`, но не 1:1 по количеству).
- Первая нейронка: **ChatGPT** — первая страница интерфейса делается под неё.
- Стиль интерфейса: дашборд, тёмные тона, просто/стильно/приятно глазу (без вычурности).

## Стек и правила (решено)
- Python 3.12, основной фреймворк — **FastAPI**.
- Все зависимости — в `.venv` проекта (создан первым шагом), НЕ глобально.
- Входящие (от пользователя) и приходящие (от нейросети) изображения хранятся в отдельном хранилище **внутри репозитория**, структура: **по датам и по направлению (вход/выход)** — чтобы сразу видеть, что и когда генерировалось.
- Дедупликация изображений обязательна: контент-хеш (например, SHA-256) → один файл, повторные ссылки на него. Экономия места + быстрая загрузка.
- Всё собирается в **Docker**; порты подбираем так, чтобы не задеть порты уже существующих docker-контейнеров (перед выбором порта проверять занятые).
- API-ключи кладутся в `.env` (не коммитить; есть `.env.example`).
