# Design Context (для скилла impeccable)

## Target audience
Один пользователь — Лев. Личный тестовый стенд: быстро проверить, как разные нейросети обрабатывают/генерируют изображения через API. Смотрит в интерфейс подолгу, по многу итераций в день.

## Use cases
- Загрузить несколько картинок → отправить в выбранную модель → посмотреть результат.
- Сравнивать результаты между моделями (вкладки) и между запусками (история по датам).
- Быстро найти: что и когда генерировалось (хранилище по датам, вход/выход).

## Brand personality / tone
- Направление подтверждено Львом (ревью дизайна, 2026-09-07): **принцип Apple — максимальное удаление лишнего**.
  Элемент не используется или не несёт реальной информации → удалить.
- Тёмная нейтральная палитра, ОДИН акцент. Ноль пестроты, ноль декоративных панелей-карточек.
- Линейная композиция: одна колонка по центру, от мобилки до 2K.
- Системный шрифт (-apple-system/Segoe UI), база 16px, минимум 14px — НЕ мельчить.
- Никаких вкладок-заглушек, капслок-лейблов, подписей-меток на изображениях.
- Пустые секции скрываются, а не показывают «заглушки-пустышки».

## Constraints
- FastAPI бэкенд, фронт — обычный HTML/CSS/JS (без тяжёлых фреймворков), собирается в Docker.
- Первая вкладка — ChatGPT; архитектура вкладок должна позволять добавлять новые модели.
- Хранилище изображений с дедупликацией (SHA-256), отдача с кэшированием.

## Differentiation
Абсолютная чистота: ничего лишнего на экране, каждая деталь работает.
